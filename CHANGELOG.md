# Changelog
Все заметные изменения проекта собраны здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).
## [1.0.0] — 2026-11-18
Первый стабильный релиз.
### Добавлено
- Локальная страница ревью в стиле GitHub Pull Request: дерево файлов,
  подсветка синтаксиса, номера строк, прогресс просмотра.
- Пять локальных режимов: незакоммиченные изменения, ветка, диапазон,
  выбранные коммиты и вся история.
- Ревью пул-реквестов GitHub через `gh`: head скачивается в служебную ссылку,
  ветка и рабочие файлы не затрагиваются.
- Инлайн-комментарии с выделением диапазона строк и вставкой скриншотов.
- Статусы комментариев: resolve и unresolve, для человека и для агента.
- Переход к определению символа и список использований.
- Переключение раскладки diff, тёмная и светлая темы, настройка отступов дерева.
- Настройки хранятся на устройстве и переживают новое ревью и перезапуск.
- MCP-сервер с инструментами `start_review`, `await_review`, `get_review`,
  `list_review_scope`, `resolve_comments`, `close_review`,
