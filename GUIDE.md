# PR Review — как этим пользоваться
Простая инструкция для человека: что это, как поставить, и как ревьюить код —
свои изменения, ветку и настоящие пул-реквесты с GitHub.
---
## Что это вообще
Обычный просмотр diff в терминале показывает изменения, но в нём неудобно
оставлять замечания, и он ничего не умеет передавать дальше. Эта утилита
поднимает **локальную веб-страницу в стиле GitHub Pull Request** — прямо на
твоём компьютере, на `http://127.0.0.1:...`.
Ты открываешь её в браузере и делаешь всё как на GitHub:
- видишь файлы, подсветку синтаксиса и номера строк;
- выделяешь мышкой диапазон строк и пишешь комментарий;
- вставляешь скриншот прямо в комментарий (`Ctrl+V`);
- переходишь к определению символа (как «Go to definition»);
- нажимаешь **Request changes / Approve** — и ревью **уходит в чат с AI**,
  который сразу начинает править код.
То есть: ты ревьюишь глазами, а рутинную правку делает нейросеть.

## 1. Первый запуск (5 минут)
### Что нужно
1. **Node.js 20+** — <https://nodejs.org> (кнопка LTS).
2. **Git** — обычно уже стоит.
3. Для ревью **пул-реквестов с GitHub** ещё нужен **GitHub CLI** (`gh`).
   Об этом отдельный раздел ниже — для обычных ревью он не нужен.
### Установка
```bash
git clone <этот-репозиторий> pr-review-mcp
cd pr-review-mcp
npm install
```
`npm install` сам проверит, есть ли `gh`. Если его нет — просто напишет
подсказку, как поставить; **ничего не сломается**.
### Запуск
```bash
# ревью того, что ты ещё не закоммитил (рабочая папка)
npm run review -- "C:\путь\к\проекту" 5454
```
В консоли появится адрес, открой его в браузере:
```
http://127.0.0.1:5454/
```
Всё. Страница живёт, пока ты её не закроешь (или пока не остановишь процесс).

## 2. Что можно ревьюить
Утилита умеет смотреть на разные «наборы изменений». Выбираешь одним флагом
`--mode`:
| Что хочешь посмотреть | Команда |
| --- | --- |
| Только незакоммиченное | `npm run review -- . --mode uncommitted` |
| Всю текущую ветку против базовой | `npm run review -- .` *(это режим по умолчанию)* |
| Конкретный диапазон коммитов | `npm run review -- . --mode range --base origin/dev --head my-branch` |
| Отдельные коммиты | `npm run review -- . --mode commits` |
| Всю историю ветки | `npm run review -- . --mode all` |
| **Настоящий PR с GitHub** | `npm run review -- . --mode pr --pr 42` |
Плюс можно указать порт (`5454`) и открыть браузер автоматически (`--open`).
